ЖИЗНЕННЫЙ ЦИКЛ СЕРВЕРА
1. run_migrations() → CREATE TABLE IF NOT EXISTS

4. [shutdown] close_pool() → graceful stop

Описание сущностей базы данных
device_categories — Категории устройств Справочник типов оборудования
ПолеТипКлючОписание
idSERIALPKАвтоинкремент
codeVARCHAR(50)UQКод: PTZ, RFID, DRONE...
nameVARCHAR(100)NNНазвание на русском
icon / icon_pathVARCHAR—Эмодзи или путь к файлу иконки
colorVARCHAR(20)—HEX-цвет маркеров на карте
zones — Зоны охраны Географические зоны объекта
ПолеТипКлючОписание
idSERIALPKАвтоинкремент
codeVARCHAR(50)UQZONE_A, PERIMETER...
nameVARCHAR(100)NNНазвание зоны
lat_center / lon_centerDECIMAL(10,7)—Координаты центра
radius_mINTEGER—Радиус для отображения
devices — Устройства Центральная сущность
ПолеТипКлючОписание
idSERIALPKСистемный ID
category_idINTEGERFK→ device_categories
zone_idINTEGERFK→ zones (NULL)
nameVARCHAR(200)NNНаименование устройства
serial/model/ipVARCHARNULLПаспортные данные (необязательны)
is_mobileBOOLEAN—Подвижный объект (дрон, патруль)
detection_rangesJSONB—[{"label","radius_m","color"}]
icon_pathVARCHAR(500)—Индивидуальная иконка на карте
device_states — Состояние устройств 1:1 с devices
ПолеТипКлючОписание
device_idINTEGERFK UQ→ devices, связь 1:1
online_statusBOOLEAN—Онлайн / Оффлайн
operational_modeVARCHAR(50)—active/idle/alarm/patrol/maintenance
battery_levelSMALLINTNULLЗаряд 0–100% (беспроводные)
signal_strengthSMALLINT—Уровень сигнала 0–100
last_heartbeatTIMESTAMPTZ—Последний пинг от устройства
extra_stateJSONB—Гибкие метрики: {"fps":25,"pan":120}
device_positions — История позиций Только подвижные объекты
ПолеТипКлючОписание
idBIGSERIALPKБольшой автоинкремент
device_idINTEGERFK→ devices CASCADE DELETE
latitude/longitudeDECIMAL(10,7)NNКоординаты, точность ~1 см
heading / speedDECIMALNULLКурс (0–360°) и скорость км/ч
is_currentBOOLEANIDXTRUE = актуальная позиция
device_metrics — Телеметрия Временной ряд, накапливается
ПолеТипКлючОписание

metric_valueDECIMAL(15,4)—Числовое значение
unitVARCHAR(20)—°C, V, %, km/h...

REST API · порт 8000
  • GET
    /api/devices — список с состоянием и зонами
  • GET
    /api/devices/{id} — детальная карточка + метрики
  • POST
    /api/devices/{id}/icon — загрузка иконки
  • GET
    /api/incidents — ?status=&severity=&limit=
  • PATCH
    /api/incidents/{uuid} — смена статуса
  • GET
    /api/zones — зоны + кол-во устройств
  • GET
    /api/zones/stats — сводная статистика системы
  • GET
    /api/categories — справочник категорий
  • WS
    ws://host:8000/ws — real-time push (готов)
  • GET
    /docs — OpenAPI документация
