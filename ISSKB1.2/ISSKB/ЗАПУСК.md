# SENTINEL — Инструкция по ручному запуску (ISSKB)

## Структура

```
D:\ISSKB\
├── security_dashboard\     ← весь код приложения
│   ├── main.py             ← точка входа сервера (порт 8001)
│   ├── start.bat           ← скрипт автозапуска
│   ├── static\             ← фронтенд (HTML/JS/CSS)
│   │   ├── logo\           ← ← ЛОГОТИП кладите сюда (PNG/SVG)
│   │   ├── icons\devices\  ← ← ИКОНКИ УСТРОЙСТВ кладите сюда

│   ├── api\                ← REST-эндпоинты
│   ├── services\           ← симулятор + heartbeat
│   └── websocket\          ← WebSocket менеджер
└── ЗАПУСК.md               ← этот файл
```

### 1. Python 3.11 или 3.12 / 3.13
Скачать: https://www.python.org/downloads/

Убедиться что установлен:

После установки запустить Docker Desktop и дождаться значка в трее (кит становится не анимированным).

## База данных — первый запуск

База данных работает в Docker-контейнере (`sentinel-postgres`).

### Если контейнер уже есть (обычный случай)

Проверить:
```
docker ps -a
```

Должна быть строка с `sentinel-postgres`. Запустить:
```
docker start sentinel-postgres
```

Проверить что работает:
```
docker exec sentinel-postgres psql -U sentinel_user -d sentinel_isskb -c "SELECT 1;"
```

### Если контейнера нет (создать с нуля)

```powershell
docker run -d `
  --name sentinel-postgres `
  -e POSTGRES_USER=sentinel_user `
  -e POSTGRES_PASSWORD=sentinel123 `
  -e POSTGRES_DB=sentinel `
  -p 5432:5432 `
  -v sentinel-pgdata:/var/lib/postgresql/data `
  --restart unless-stopped `
  postgres:16-alpine
```

Подождать 5-10 секунд, затем создать базу для ISSKB:
```
docker exec sentinel-postgres psql -U sentinel_user -d sentinel -c "CREATE DATABASE sentinel_isskb OWNER sentinel_user;"
```

## Запуск приложения

### Способ 1 — Через start.bat (рекомендуется)

1. Открыть `D:\ISSKB\security_dashboard\`
2. Дважды щёлкнуть `start.bat`
3. Подождать строку `Application startup complete.`
4. Открыть браузер: **http://localhost:8001**

При первом запуске схема БД создаётся автоматически, данные сидируются (22 устройства, 5 инцидентов).

### Способ 2 — Вручную через PowerShell

```powershell
# Запустить БД
docker start sentinel-postgres

# Перейти в папку
cd D:\ISSKB\security_dashboard

# Запустить сервер
$env:PYTHONUTF8 = "1"
python main.py
```

Открыть: **http://localhost:8001**

## Куда класть изображения

### Логотип (левый верхний угол)

**Способ 1 — через браузер:**
- Нажмите на логотип в левом верхнем углу интерфейса
- Выберите файл PNG/SVG/JPG
- Логотип сохранится автоматически

**Способ 2 — вручную:**
Скопируйте файл в:
```
D:\ISSKB\security_dashboard\static\logo\
```
Назовите файл `logo.png` (или `logo.svg`, `logo.jpg`).
После этого перезапустите сервер или нажмите F5 в браузере.

---

### Иконки устройств (маркеры на карте и в панели)

**Способ 1 — через браузер:**
- Выберите устройство в боковой панели
- В правой панели нажмите на иконку устройства (появится курсор-загрузчик)
- Выберите файл PNG/SVG

**Способ 2 — вручную:**
Скопируйте файл в:
```
D:\ISSKB\security_dashboard\static\icons\devices\
```
Назовите файл `{ID_устройства}.png`, например `26.png`.

ID устройства можно узнать в браузере: выбрать устройство → в адресной строке нет ID, но он виден в API:
```
http://localhost:8001/api/devices
```
(поле `"id"` в каждом объекте)

Затем выполните в базе:
```sql
UPDATE devices SET icon_path = '/static/icons/devices/26.png' WHERE id = 26;
```

## Управление базой данных

### Подключиться к БД напрямую

```powershell
docker exec -it sentinel-postgres psql -U sentinel_user -d sentinel_isskb
```

Полезные команды внутри psql:
```sql
\dt                          -- список таблиц
SELECT * FROM devices;       -- все устройства
SELECT * FROM incidents;     -- все инциденты
UPDATE devices SET name = 'Камера въезда' WHERE serial_number = 'SN-001';
UPDATE devices SET responsible_person = 'Иванов И.И.' WHERE id = 26;
\q                           -- выйти
```

### Полный сброс данных (пересев)

```powershell
cd D:\ISSKB\security_dashboard
$env:PYTHONUTF8 = "1"
python clear_db.py
```

После этого при следующем запуске сервера данные создадутся заново автоматически.

### Резервная копия БД

```powershell
docker exec sentinel-postgres pg_dump -U sentinel_user sentinel_isskb > D:\ISSKB\backup.sql
```

Восстановление:
```powershell
Get-Content D:\ISSKB\backup.sql | docker exec -i sentinel-postgres psql -U sentinel_user -d sentinel_isskb
```

## Диагностика

### Сервер не запускается
```powershell
# Проверить что порт 8001 свободен
netstat -an | findstr "8001"

# Проверить что Python установлен
python --version

# Проверить что библиотеки установлены
python -c "import fastapi, uvicorn, asyncpg; print('OK')"
```

### База данных недоступна
```powershell
# Проверить что контейнер запущен
docker ps | findstr sentinel-postgres

# Запустить если остановлен
docker start sentinel-postgres

# Проверить подключение
docker exec sentinel-postgres psql -U sentinel_user -d sentinel_isskb -c "SELECT 1;"
```

### Карта не отображается
Тайлы карты расположены в `D:\ISSKB\security_dashboard\tiles\`.
Проверить статус:
```
http://localhost:8001/tiles/status
```

### Логи сервера
```powershell
# Если запущен через start.bat — смотреть прямо в окне CMD
# Если через PowerShell — вывод прямо в консоль

# Если запущен в фоне:
Get-Content D:\ISSKB\security_dashboard\server_out.txt -Tail 30
Get-Content D:\ISSKB\security_dashboard\server_err.txt -Tail 30
```

## Остановка

- Если запущен через start.bat или PowerShell: `Ctrl+C`
- Принудительно:
```powershell
Get-Process python | Stop-Process -Force
```

База данных (Docker) продолжает работать в фоне и запустится автоматически при следующем старте Windows (флаг `--restart unless-stopped`).

Если нужно остановить и Docker:
```powershell
docker stop sentinel-postgres
```
